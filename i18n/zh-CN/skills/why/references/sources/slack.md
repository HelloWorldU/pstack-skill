# Slack 对话

## 如何搜索

Slack MCP 的工具各不相同。先确认当前可用的是哪个 Slack MCP，并检查它的工具 schema。它可能要求 `mcp_auth`。如果认证失败，停下来并报告缺口。

1. **限定作者的搜索。** PR 作者在 PR 合并日期前后发的消息。能大幅缩小范围，而且常常一击即中。
3. **PR URL 搜索。** PR 在被评审或讨论时经常被贴到 Slack。搜索 PR 的 URL（或者只搜 `/pull/<number>`）。
4. **错误字符串搜索。** 如果代码处理某个特定错误，搜索这个错误字符串。事故讨论串常常会浮出水面。

## 常见陷阱

- **频道考古的极限。** 很旧的消息可能因留存策略被删除。如果某个日期之前什么都找不到，记下这个留存断崖。
- **搜不到的私信。** 很多决策发生在无法搜索的私信里。你会错过它们。这是已知局限。
- **把随口的玩笑当“决策”。** Slack 很随意。“Lol just do the thing” 不是决策，即使它出现在提交之前。要找经过考虑的讨论。
- **单条消息的语境坍缩。** 没有讨论串，一条单独消息的读法常常与在上下文中不同。务必拉取完整讨论串。
- **认证失败。** 如果 MCP 没有通过认证，停下来。不要编造发现。报告 Slack 无法搜索即可。
